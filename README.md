# ai-lab

Small experiments that run in the browser. Each one lives in its own numbered
folder and is published to GitHub Pages under the same name.

**▶ Play Breakwater GP: https://coderitual.github.io/ai-lab/01-breakwater-gp/**

**▶ See Backlit Swan: https://coderitual.github.io/ai-lab/02-backlit-swan/**

All demos: https://coderitual.github.io/ai-lab/

| #  | Demo | Play |
| -- | ---- | ---- |
| 01 | [Breakwater GP](01-breakwater-gp/) — an original powerboat slalom race on simulated waves, built with three.js. Solo, two-player split screen, or up to four players online with no server | https://coderitual.github.io/ai-lab/01-breakwater-gp/ |
| 02 | [Backlit Swan](02-backlit-swan/) — a mute swan on a dark forest pond, backlit by low sun: eleven seconds of film measured and rebuilt as an interactive real-time scene, built with three.js. Drag to look round, touch the water, ask the swan to shake, dunk and reach | https://coderitual.github.io/ai-lab/02-backlit-swan/ |

Each demo documents itself in its own `docs/` folder: what it is meant to be,
what the build does, how the tricky parts work, and what to do next. The
pictures there are generated by a script, so they stay current.
[Breakwater GP's docs](01-breakwater-gp/docs/),
[Backlit Swan's docs](02-backlit-swan/docs/).

## Publishing

`.github/workflows/pages.yml` runs on every push to the default branch. It
builds each `NN-name/` folder that has a `package.json` with a `build` script
and publishes its `dist/` at `https://coderitual.github.io/ai-lab/NN-name/`,
plus an index page at the site root.

One-time setup: repository **Settings → Pages → Build and deployment →
Source: GitHub Actions**.

To add a demo, create `02-name/` whose `npm run build` writes a static site to
`dist/` using relative asset paths (for Vite: `base: './'`). Set `displayName`
and `description` in its `package.json`; they are shown on the index page.

Build the whole site locally with `node scripts/build-site.mjs` (output in
`_site/`).
